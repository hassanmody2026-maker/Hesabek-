حسابك HESABAK - الإصدار 3

ارفع كل محتويات هذا المجلد إلى استضافة HTTPS واحدة (مثل Netlify) مع الحفاظ على المجلد icons. افتح رابط الموقع من Chrome ثم اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

مزامنة السحابة تحتاج اتصال إنترنت وتسجيل الدخول بنفس الحساب. المزامنة الاحتياطية تفحص التغييرات تلقائيًا كل 3 ثوانٍ، وقد يتطلب ظهور التغيير إعادة تحميل تلقائية للتطبيق.

تنبيه: الاشتراكات الشهرية والسنوية وحالتها وتنبيهات الانتهاء موجودة داخل التطبيق، أما تحصيل المدفوعات والتجديد الآلي فيحتاجان بوابة دفع وخادمًا آمنًا.
